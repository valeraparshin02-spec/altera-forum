# Форум Альтеры 2027

Сайт форума «Стратегии и тренды рынка недвижимости».
Дата: 16–17 апреля 2027. Казань, IT-парк имени Башира Рамеева.

Статический HTML/CSS/JavaScript с локальной библиотекой Three.js. Единственный опубликованный дизайн — «Точка притяжения».

## Публикация
GitHub Pages: ветка `main`, корень репозитория. После push сайт обновляется автоматически.

## Файлы
- `index.html` — главная страница.
- `concepts/orbit/orbit.css` и `orbit.js` — оформление и анимация.
- `concepts/orbit/index.html` — тот же сайт по вложенному адресу; при изменении содержания обновлять обе HTML-копии.
- `assets/` — логотип, фотографии и видео первого форума.
- `concepts/assets/` — шрифты.
- `concepts/orbit/vendor/LICENSE-three.txt` — лицензия Three.js.

## Локальный просмотр
Запустить `python -m http.server 8769` из корня репозитория и открыть `http://localhost:8769/`.

Продажа билетов пока не подключена; программа и спикеры готовятся к анонсу.
